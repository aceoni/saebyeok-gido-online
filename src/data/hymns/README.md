# 배경 찬양 악보 데이터

곡마다 JSON 파일 하나입니다. 재생 순서는 `index.ts`에서 정합니다.
수정한 뒤 `npm run check:hymns`를 실행하면 마디마다 박 수가 맞는지 검사합니다.

## 곡 정보
| 필드 | 뜻 |
|---|---|
| `title`, `titleEn`, `hymnal` | 한국어 제목, 영어 제목, 새찬송가 장 |
| `tune`, `composer`, `year`, `source` | 곡조 이름, 작곡자, 작곡 연도, 출처와 편곡 정보 |
| `key`, `meter`, `bpm` | 조, 박자(`[3, 4]` = 3/4), 빠르기(4분음표 기준 1분당 박 수) |

## 마디 (`measures`)
```json
{ "m": 5, "rh": "G4/2 B4/.5 G4/.5", "lh": "G2/1 D3+B3/2", "dyn": "p", "end": true }
```
- `m`: 마디 번호. 곡이 못갖춘마디로 시작하면 그 마디가 0번, 첫 온마디가 1번입니다.
- `rh`: 오른손(멜로디), `lh`: 왼손(반주). 음을 공백으로 구분해 순서대로 적습니다.
- 음 하나 = `음이름옥타브/박`
  - `G4/1` = 가운데 도(C4) 위의 솔, 1박(4분음표)
  - `/2` = 2박(2분음표), `/3` = 점2분음표, `/.5` = 8분음표, `/1.5` = 점4분음표
  - `#` = 올림, `b` = 내림 (`F#4`, `Bb3`). **조표는 자동으로 붙지 않으므로** 내림/올림을 매번 직접 적습니다.
  - 화음: `+`로 묶습니다. `D3+B3/2` = 레와 시를 함께 2박
  - 쉼표: `r/1`
  - 붙임줄: 끝에 `~`를 붙이면 다음 음(다음 마디여도 됨)과 이어서 한 번만 칩니다. `D5/3~` 다음에 `D5/2`
- `dyn`: 이 마디부터의 셈여림 (`pp`, `p`, `mp`, `mf`)
- `end`: 프레이즈(가사 한 줄) 끝. 이 마디는 살짝 느려지고 숨을 쉽니다.

멜로디는 Open Hymnal Project의 퍼블릭 도메인 악보를 그대로 옮겼고, 왼손 반주는 직접 단순하게 편곡했습니다.
조(key)는 그 악보를 따랐기 때문에 새찬송가와 다를 수 있습니다.
